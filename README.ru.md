# podcast-studio — коротко по-русски

ИИ-агент монтирует подкаст из дорожек ведущих: синхронизация 2–5 дорожек, расшифровка, монтаж по тексту,
джинглы, мастеринг. Работает с Claude Code, Codex, Cursor.

Каждый пишется сам, вы кладёте файлы в папку и говорите агенту словами: «начинаем выпуск 12»,
«вырежи, где мы спорим про кофе», «второй голос чуть опаздывает». Агент сам запускает команды,
даёт послушать каждую правку и собирает MP3 с главами. Отвечает он на вашем языке.

Как поставить за 5 минут, что нужно и как выбрать между AssemblyAI и Whisper — в [README.md](README.md) (по-английски).

Главное:
- нужен Python 3.10+ и ffmpeg;
- ключ AssemblyAI кладёте сами в `~/.config/podcast-studio/credentials` — агенту в чат его не присылайте;
- ваши исходные файлы студия не меняет.
